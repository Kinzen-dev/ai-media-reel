The smallest grammar.

K and P consume one input and produce one stitch. YO consumes none and produces one. K2tog consumes two and produces one. Brackets repeat operations one to nine times.

One ASCII space separates terms. Exact case, no nested repeats, no trimming and no silent repair. Source offsets count UTF-16 code units, starting at zero.

Read first. Then count.

Every row is parsed completely before any operation executes. Syntax failures execute nothing. Execution failures stop before the first operation that cannot consume its input. Leftover input is an error at the end of the source.

A failed row has no valid output. Later rows remain Blocked with no derived input, consumed count or output. Preparing those statuses does not validate them.

Original count-only grammar, not a full knitting notation parser, garment fit test or practical knitting advice. The paper, needle and loops are illustrations of this local count model.
